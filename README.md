# CuePlay (キュープレイ)

ブラウザ上で動作するアナログ風サンプラー。
音声ファイル（mp3, wav等）を読み込んで、直感的な操作で再生・編集が可能なアプリです。
演劇や配信のポン出しにも活用できます。

## 主な特徴

- **合計120個のオーディオパッド**: ページごとの切り替えにより、膨大なサンプルを直感的に配置・管理できます。
- **音声の録音機能**: マイクから直接音をサンプリングし、パッドへアサイン可能。
- **柔軟な再生モード切り替え**: 
  - `ONESHOT`: トリムされた最後まで再生
  - `RETRIGGER`: 再生中に再度パッドを叩くと最初から再生し直す
  - `TOGGLE`: タップで再生開始、再度タップで停止
  - `GATE`: 押している間のみ再生
- **トラック毎の豊富なエフェクト加工・設定機能**: 
  - 音量・ピッチ・トリム（再生範囲）・フェードイン/アウト
  - 個々に設定可能なリバーブ、ディレイ
  - Radio/Muffleなどの特殊なフィルターエフェクト
  - Mute/Solo設定など
- **ミキサー＆マスターエフェクト機能**: 各チャンネル（あるいは全体）の音量・パン調整、3バンドEQ、マスターエフェクト（Reverb, Delay, Chorus, Distortion等）を搭載し、本格的なサウンドメイクが可能です。
- **プロジェクト保存・読込**: アサインしたサンプルデータやエフェクトの設定をJSONファイルとしてダウンロード＆復元できます（Chrome環境などでは音声ファイルのBase64化によりサウンドごと保存可能です）。

## 使い方

1. アプリケーションを開き、右上の「LOAD」やパッドへのドラッグ＆ドロップで音声を読み込むか、マイクを使って音声を録音します。
2. 左側のパッドエリア（マトリクス）をクリック、またはキーボード（1〜8、Q〜I等）で音を再生します。
3. 気に入ったサウンドは、パッド右上の歯車アイコンから詳細設定ウィンドウを開いて調整できます。
4. 右部のミキサーセクションで音量のバランスを取り、サウンドを仕上げます。
